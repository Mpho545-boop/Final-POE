# Paws & Hearts Animal Shelter Website

## 1. Introduction

Paws & Hearts Animal Shelter is a website created to promote animal
adoption and support the welfare of homeless, abandoned and neglected
dogs and cats.

The main purpose of the website is to provide visitors with information
about the shelter, introduce pets that are available for adoption and
make it easier for people to contact the organisation.

## 2. Website Objectives

The objectives of the website are to:

- Promote the adoption of dogs and cats.
- Provide information about the animal shelter.
- Display pets that are available for adoption.
- Inform visitors about the services offered.
- Allow visitors to make adoption enquiries.
- Provide contact information for the shelter.
- Encourage responsible pet ownership and animal welfare.

## 3. Website Pages

The website contains the following pages:

| Page | Description |
|------|-------------|
| index.html | The homepage introduces the shelter and highlights its services and pets. |
| about.html | Provides information about the shelter and its mission. |
| services.html | Describes the services offered by the shelter. |
| pets.html | Displays dogs and cats available for adoption. |
| events.html | Provides information about shelter events and activities. |
| enquiry.html | Allows visitors to complete an adoption enquiry form. |
| contact.html | Provides contact information and a contact form. |
| privacy.html | Explains how visitors' personal information should be handled. |


## 4. Technologies Used

The website was developed using:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the pages, colours, layouts and design.
- **JavaScript:** Used to add interactive features and improve navigation.
- **Visual Studio Code:** Used as the code editor.
- **GitHub:** Used to store and manage the website source code.

## 5. Website Features

The website includes:

- Navigation links connecting all website pages.
- A homepage introducing the animal shelter.
- Pet cards displaying available dogs and cats.
- Search and filtering options for pets.
- Adoption enquiry forms.
- Contact information and a contact form.
- Responsive design for different screen sizes.
- Consistent styling across the website.
- A privacy policy page.
